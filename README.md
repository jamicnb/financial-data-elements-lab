# 金融行业数据资产分布、交易机制与价值实现研究

数据要素价格实验室实习研究项目。围绕中国内地金融行业，研究数据资产的主体与权利关系、交易与定价、价值创造及收益分配，并讨论政策和技术发展。研究基准为《金融行业数据要素研究报告 V1.0 学术排版优化版》，网站运行内容沿用已验收的RC4。

研究样本截至 **2026-11-15**，关键事实与文献复核至 **2026-11-19**。本次发布只修订仓库说明，不改变RC4的网站代码、数据、SVG或研究工具规则。

## 研究方法与样本

采用公开材料驱动的目的性案例研究：按来源及证据性质分类，核对采购公告与公开案例披露，比较产品配置、期限、账号、接口、授权及服务条件，再分析定价与收益分配机制。

收录 **15条金融数据研究案例、24条价格证据、6条多主体合作案例**。合作案例与交易案例存在交叉；24条价格证据包含报价、预算、限价、成交/合同金额和同包分项，不能视为24笔独立成交。样本受公开披露条件限制，不是全国市场总体、随机抽样或行业规模统计；没有据此计算行业均价或因果价格贡献系数。

## 四项主要发现

1. **分布研究应同时识别主体、业务和权利关系。** 数据存放或持有不等于完整经营权，数据不移动也可能形成有边界的使用能力，不能据案例列举推断行业份额。
2. **价格差异首先需要合同条件解释。** 金额对应账号、模块、API、期限、许可与持续服务组合；跨配置、跨期限或跨币种总额不能直接排名或推断同配置降价。
3. **收益分配应从可验证的净收益与责任开始。** 合同付款不等于贡献比例、利润或合作剩余；先明确结算基数、投入、权利与风险，再讨论分配机制。
4. **估值创新以可审计的合同和运营数据为前提。** 政策及安全技术改善治理和记录条件，不能自行生成通用现金流、折现率或真实分润比例。

## 网站内容

六个模块：研究概览、数据分布、交易与定价、价值与分配、政策趋势、研究证据与工具。提供案例搜索及组合筛选、证据详情、合同比较、交互关系图、政策时间线和三份研究辅助表单。表单在浏览器本地处理，不上传用户输入。

## 证据边界

C007仍为条件确认，未证合同金额及字段不作已确认事实展示。C014历史失败公告及后续结果待复核，不能由404推断后续有无成交。MC004为创新应用声明书所载设计，独立运营与收益待证；MC006仅披露“数据产品调用＋场景赋能分成”机制，分成比例、基数及结算结果未公开。

合同金额不等于数据本体价值，合同付款不等于可分配利润。三份工具属于本研究的分析辅助框架，并非国家标准、正式资产评估或审计结论；缺失信息不当作零，不输出无证据的估值或分配比例。部分官方来源存在动态访问、超时或失效限制，站点保留核验说明。

## 本地运行与Pages

本站使用HTML、CSS、JavaScript和SVG，无后端、数据库或构建依赖。可直接打开 `index.html`，也可在仅含网站文件的目录运行：

```text
python -m http.server 8000 --bind 127.0.0.1
```

然后访问本机8000端口。GitHub Pages采用main分支、`/(root)`目录；资源为相对路径，保留 `.nojekyll`。线上部署及公开访问应以实际验收结果为准。
